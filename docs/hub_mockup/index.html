Hub du scientifique : maquettes

Écrans du hub entre deux parties, à taille réelle (1280 × 720 logiques, la taille de référence du jeu). Plan, règles et modèle de données : docs/HUB_PLAN.md. Une fois validée, l'intégration suit cette maquette exactement.

Style : interface pas cubique mais en harmonie avec le jeu (contour noir, coins nets, ombres pleines, barres en cubes, icônes en pixel art). Palette du décor DECOR_PALETTE ; couleurs de rareté du jeu.

Données d'exemple : profil niveau 7, échantillons des chiens seulement. Noms d'armes fictifs de maquette (les armes réelles du jeu actuel doivent être renommées, GAME_CONCEPT §4.9). Date fictive de la maquette : 18 novembre 2026.
